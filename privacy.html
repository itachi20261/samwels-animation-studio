Privacy Policy

Last updated: September 13, 2026

1. About this application

Samwels Animation Studio is an AI-assisted 2D animation development environment used for character design, visual research, reference organization, and animation planning.

2. Information accessed

When connected to supported services, the application may access publicly available visual references and information needed to organize those references for creative development.

3. Pinterest data

If Pinterest integration is enabled, the application may access Pinterest data permitted by the Pinterest API and by the permissions granted by the user. This data is used for visual research, reference selection, and animation development.

4. Use of information

Information accessed by the application is used only to support the studio's creative workflow, including research, character design, visual development, and animation planning.

5. Data sharing

The application does not sell personal information. Information is not shared with third parties except when necessary to use an enabled service or when required by law.

6. Data security

Reasonable measures are used to protect information handled by the application. No method of electronic storage or transmission is guaranteed to be completely secure.

7. Contact

For questions about this privacy policy, contact the developer through the Samwels Animation Studio GitHub repository.
